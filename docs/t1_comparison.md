# T1. Сравнительный анализ генераторов статических сайтов

## Постановка

Требуется сравнить не менее четырёх генераторов статических сайтов (SSG) на Python
применительно к задаче **публикации результатов экспериментов**.
Обязательные кандидаты: MkDocs (Material), Sphinx (MyST-Parser), Pelican.
Четвёртый — Jupyter Book 2 (MyST-MD).

## Вывод

**Оптимальный генератор — Sphinx (MyST-Parser): 4.84 из 5.**

Он набирает максимум по ключевым для публикации результатов критериям:
нумерация уравнений и ссылки, окружения `amsmath`, перекрёстные ссылки,
исполнение ноутбуков с кэшем, BibTeX, экспорт в LaTeX/PDF, автодокументирование.

**Условия, при которых вывод меняется:**

- Если нет формул со ссылками, BibTeX и исполняемого кода — Sphinx избыточен,
  выгоднее **MkDocs** (лучше вёрстка, навигация, мобильное поведение).
- Если приоритет — Typst-PDF и современный MyST-стек — **Jupyter Book 2**
  становится конкурентоспособным, но уступает по зрелости и версионированию.
- **Pelican** не подходит для научного контента: формулы и перекрёстные ссылки
  требуют плагинов, которые не покрывают весь сценарий.
