# T1. Матрица критериев (детально)

Здесь — развёрнутые пояснения по каждому критерию для каждого генератора.

## Представление научного контента

### Формат исходников

- **MkDocs** — Markdown. Расширения через плагины.
- **Sphinx** — reStructuredText и MyST (надмножество Markdown).
- **Jupyter Book 2** — MyST-MD, унифицированный синтаксис.
- **Pelican** — Markdown и reST, но без научных расширений.

### Формулы LaTeX

- **MkDocs** — MathJax/KaTeX через `pymdownx.arithmatex`. Нумерация вручную.
- **Sphinx** — MathJax по умолчанию, полный разбор `amsmath`, автонумерация,
  ссылки через `{eq}`.
- **Jupyter Book 2** — MathJax/KaTeX, `{eq}` и `{numref}` на уровне MyST.
- **Pelican** — только инъекция MathJax, без нумерации и ссылок.

### Рисунки, таблицы, перекрёстные ссылки

- **Sphinx** — `numref`, автонумерация, подписи, подрисунки.
- **Jupyter Book 2** — `{numref}`, `{figure}`, `{list-table}`.
- **MkDocs** — базово, через плагины, без автонумерации.
- **Pelican** — практически не поддерживается.

### Исполняемый контент

- **Sphinx** — `myst-nb`, зрелое решение.
- **Jupyter Book 2** — встроено, управляемый кэш.
- **MkDocs** — `mknotebooks`, не ядро.
- **Pelican** — нет.

### Библиография

- **Sphinx** — `sphinxcontrib-bibtex`, нативно.
- **Jupyter Book 2** — нативный синтаксис MyST.
- **MkDocs** — сторонние плагины.
- **Pelican** — нестабильно.

## Вёрстка и шаблоны

- **MkDocs Material** — сильнейшая многоколоночная вёрстка (grid/cards),
  оптимизирован под мобильные.
- **Sphinx** — через `sphinx-design`, гибкое переопределение Jinja2.
- **Jupyter Book 2** — современный адаптив, но API override ещё зреет.
- **Pelican** — зависит от темы, универсальность низкая.

## Эксплуатация

- **Версионирование**: `mike` (MkDocs), `sphinx-multiversion` (Sphinx),
  у JB2 и Pelican стабильного решения нет.
- **Поиск по русскому**: Sphinx настраивается лучше всех, MkDocs — средне,
  JB2 — новый алгоритм, не проверен на русском.
- **i18n**: нативно у Sphinx (`sphinx-intl`), у остальных — плагины или нет.
- **Автодок из docstrings**: только Sphinx (`autodoc`).
- **Зрелость**: Sphinx — 20+ лет, MkDocs — средне-высокая,
  JB2 — быстро растёт, Pelican — поддержка неактивна.
